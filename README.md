# Reverse K-Group Linked List

A Java implementation of the **Reverse Linked List in Groups of K** problem using an iterative approach and pointer manipulation.

## Problem
Given a singly linked list and an integer `k`, reverse the nodes in groups of `k`. If fewer than `k` nodes remain at the end, keep those nodes in their original order.

The algorithm changes node links only; it does not change node values.

## Run
Open the project folder in a terminal and execute:

```bash
javac Main.java
java Main
```

## Sample Input
```text
5
1 2 3 4 5
2
```

## Sample Output
```text
Original Linked List:
1 -> 2 -> 3 -> 4 -> 5
Linked List after reversing in groups of 2:
2 -> 1 -> 4 -> 3 -> 5
```

## Complexity
- **Time:** O(n)
- **Auxiliary space:** O(1)
